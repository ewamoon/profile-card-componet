## Built with

- Semantic HTML5

- Flexbox
- Responsive design

## What I practiced

- Building a component from a Figma design
- Creating responsive layouts with `width` and `max-width`
- Working with Flexbox
- Positioning elements with `position: relative` and `position: absolute`
- Working with multiple background images and `background-position`
- Styling typography and spacing based on a design
- Using semantic HTML for profile statistics
- Using Git and GitHub to track project changes

## What I learned

This project helped me better understand how parent and child elements affect each other's size and positioning. I also practiced the difference between `margin` and `padding`, positioning an element across two sections of a card, and matching dimensions and spacing from a Figma design.
